Mocht je willen weten wanneer je naar de les moet en dit nog niet in je agenda hebt gezet kan dit ook volledig autonoom via de PAULO agenda synchronisatie! Hier leg ik je even stap voor stap uit hoe je een link verkrijgt om direct in je agenda van keuze kan importeren.

| Meerwaarden                                                                                                                                              | Minpunten                                              |
| -------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| 1. Je moet niet meer naar het papieren bladje kijken<br>2. De agenda blijft altijd up-to-date<br>3. Indien ingesteld zal dit ook een push-melding sturen | 1. Je hebt toch een minuutje of 5 nodig om dit te doen |
## Verkrijgen van de link via het PAULO extranet
> https://extranet.paulo.be/opleidingen/agenda

Surf naar het PAULO extranet *(link hierboven)* en log in. Je krijgt vanzelf de agenda te zien als je de linkt volgt. Zo niet: volg de afbeeldingen hieronder

## Importeren in agenda van keuze
Mocht je weten hoe je dit doet kan je het skippen en ben je eigenlijk klaar. Zoniet raadpleeg de foto's en/of doorgelinkte handleidingen
### Importeren in Google Calendar
> https://calendar.google.com/calendar/u/0/r

Surf via een laptop naar de Google Calendar applicatie *(en log desnoods in)*

| 1. Klik op het plusje aan de zijkant bij `Andere Agenda's` -> `Via URL` |
| ----------------------------------------------------------------------- |
| ![[Pasted image 20260912211614.png]]                                    |

| 2. Plak de link in het vakje en klik op `Agenda toevoegen` |     |
| ---------------------------------------------------------- | --- |
| ![[Pasted image 20260912212054.png]]                       |     |


| 3. Je ziet `Opleiding Basiscursus - PAULO` verschijnen op dagen van les |     |

### Andere agendasystemen
Voor andere agenda's blijft het even gemakkelijk, maar moet je even de handleiding raadplegen van dat specifiek type. Ik lijst er hier de populaire op, maar is uiteindelijk gewoon een 'agenda via link importeren' en kan bij iedere agenda.
- Apple Kalender: https://support.apple.com/nl-be/guide/calendar/icl1022/mac
- Outlook: https://support.microsoft.com/nl-nl/outlook/import-or-subscribe-to-a-calendar-in-outlook-com-or-outlook-on-the-web
