# PQRST

Dit is een methode om informatie over de pijn bij de patiënt te bevragen waarbij elke letter een categorie aangeeft:
- Provoking factors = uitlokkende factoren : welke zijn de uitlokkende factoren? wat was de patiënt aan het doen toen de pijn begon?
- Quality = kwaliteit : hoe is de pijn, is deze stekend, brandend, scherp? heeft de patiënt een snoerend of beklemmend gevoel?
- Radiation = uitstraling : straalt de pijn uit of is deze gelokaliseerd?
- Severity = ernst symptomen : hoe erg is de pijn? zijn er geassocieerde symptomen (bvb dyspnoe)?
- Time = tijd : wanneer is de pijn begonnen? hoe lang duurt de pijn?
